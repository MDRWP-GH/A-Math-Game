# การย้ายบัญชีและเซฟ A-Math ข้ามเครื่อง

สำหรับเกมเวอร์ชัน Windows ข้อมูลอยู่ที่โฟลเดอร์ `save` ข้าง `A-Math.exe` โดยหนึ่งบัญชีอยู่ใน `save/users/<ชื่อบัญชี>--<Account ID>` หนึ่งโฟลเดอร์ ภายในมีข้อมูลล็อกอิน ชื่อในเกม รหัสผู้เล่นสำหรับกลับเข้าห้อง บทสอน เซฟ และประวัติ/replay

1. ปิดเกมบนทั้งสองเครื่อง และสำรอง `save` ของเครื่องปลายทางก่อน
2. คัดลอกเฉพาะโฟลเดอร์บัญชีที่ต้องการจาก `save/users` ของเครื่องต้นทาง ไปที่ `save/users` ของเครื่องปลายทาง **โดยไม่เขียนทับ** โฟลเดอร์เดิม
3. เปิดเกมบนเครื่องปลายทางแล้วกรอก Username และ Password เดิมครั้งแรก หลังจากนั้น Auto Login จะทำงานบนเครื่องปลายทางตามปกติ

Auto Login และการตั้งค่าภาษา เสียง และภาพเป็นข้อมูลเฉพาะเครื่อง ไม่ย้ายไปกับบัญชี หากพบชื่อบัญชีหรือ Account ID ซ้ำ เกมจะไม่เลือกบัญชีแทนผู้ใช้ ให้สำรองทั้งสองโฟลเดอร์ก่อนแก้ความขัดแย้ง

ถ้าเกมแจ้งว่าเขียน `save` ไม่ได้ ให้ย้ายโฟลเดอร์เกมทั้งชุดไปยังตำแหน่งที่บัญชี Windows เขียนไฟล์ได้ แล้วเปิดเกมใหม่ อย่าวางเกมในตำแหน่งที่ต้องใช้สิทธิ์ Administrator เพื่อบันทึกข้อมูล

ข้อมูลรุ่นเก่าใน LocalLow จะถูกคัดลอกเข้ารูปแบบใหม่นับครั้งแรกที่ `save/users` ยังไม่มีบัญชี ต้นฉบับไม่ถูกลบ หากมีบัญชีใน `save/users` แล้ว เกมจะไม่รวมข้อมูลเก่าหรือเขียนทับอัตโนมัติ
